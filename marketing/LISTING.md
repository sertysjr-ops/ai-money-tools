## Long description

Every AI writing tool wants $20/month and your data. dani-tools is the
opposite: 8 zero-dependency command-line tools that run against the free,
local model already on your machine (Ollama). No API keys. No cloud bills.
No telemetry. No subscription — ever.

**What you get:**

- 🧵 **threadsmith** — long-form text → ready-to-post Twitter/X thread
- ⛏️ **quotemine** — the 10 most screenshot-worthy lines from any text, ranked
- 💬 **replyguy** — multi-tone reply drafts (witty, professional, agree/disagree)
- 📋 **changelogify** — git history → release notes your users actually read
- 🪝 **hookline** — scroll-stopping cold-open hooks for any topic
- 🏷️ **namelab** — product names with domain hints (startup/premium/playful/technical)
- ❓ **faqforge** — your docs → a self-contained, zero-JS FAQ page
- 🅰️ **altmaker** — A/B viral angles: same idea, 5 different framings with the "why"
- 🤝 **pitchforge** — cold outreach (DM/email) that leads with them, not you

**The creator tier difference:** every tool accepts a full system-prompt
override via one config file. Generic AI output sounds generic — make the
tools sound like YOU. Your flags, your prompts, your voice, saved once and
applied everywhere.

**Bonus: 5 pro persona packs included.** Don't want to write your own
prompts? Point one env var at a pack and all 9 tools instantly speak that
voice: 🔥 Viral Creator (X growth), 🛠 Indie Hacker (build-in-public),
💼 Agency Pro (client-safe polish), ⚙️ Technical Founder (dev-audience
precision), and 🎩 Ghostwriter LI (LinkedIn thought leadership). Each pack
also tunes the flag defaults — 40 hand-written prompts, battle-tested
against the parsers.

**Bonus: automation-ready.** A built-in local JSON API (with batch mode)
plugs all 9 tools into n8n, Make, or Zapier as webhook steps. Your content
pipeline, on autopilot, still offline.

**Bonus: browser playground.** Don't love terminals? Start the server and
open http://127.0.0.1:7890 — a dark, zero-setup web UI with a tool picker,
per-tool flag forms, and a copy button. Same tools, same local model.

**Requirements:** Node.js 18+, Ollama with one free model (setup in 5 min,
guide included). Mac/Linux/Windows.

**What's in the zip:** all 9 tools, the dispatcher, the automation server
+ browser playground, 5 persona prompt packs, config example, zsh
completions, install guide, MIT license.

## FAQ (for the listing)

**Do I need an OpenAI key?** No. Everything runs on a free local model via
Ollama. Total ongoing cost: $0.

**Is my text sent anywhere?** No. It never leaves your machine.

**What if I don't like it?** Gumroad's standard refund window applies —
but run `npm test` after install; if your machine runs Ollama, it works.

**Can I use it commercially?** MIT licensed. Yes.
